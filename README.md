# FT-Transformer

Tutorial para a disciplina de Redes Neurais sobre o [FT-Transformer](https://arxiv.org/abs/2106.11959) (Gorishniy et al., 2021) para dados tabulares usando [`rtdl_revisiting_models`](https://github.com/yandex-research/rtdl-revisiting-models), com foco nos hiperparâmetros e em busca com Optuna.

```bash
pip install rtdl_revisiting_models optuna scikit-learn torch
```

Abra `ft_transformer_tutorial.ipynb` e execute as células em ordem.
